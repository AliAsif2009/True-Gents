TRUE GENTS — Website v1.0
========================

MAIN FILE: True Gents.html
Open this file in Chrome, Edge, or Firefox to preview the site.

The site is a standalone HTML/CSS/JavaScript website; no installation or build is required. Google Fonts and photo backgrounds need an internet connection.

DESIGN
- Black / gold premium grooming identity
- Video-reference-inspired bold typography, full-screen imagery and scroll scenes
- Sticky scroll storytelling, animated marquee and scroll-triggered reveals
- Services, lookbook, story, booking CTA, responsive navigation
- Mobile friendly; respects reduced motion accessibility setting

DEMO CONTENT THAT NEEDS CLIENT DETAILS
- Salon's exact address, contact, socials, opening hours
- Actual service list and rates
- Real salon photos instead of temporary stock photo URLs
- Working booking link or WhatsApp number (currently shows a demo notification)

HOW TO REQUEST EDITS
Send your changes and mention 'True Gents v1'. The full updated main HTML file will be provided as the next version.
